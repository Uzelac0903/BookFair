# BookFair — Sistem za upravljanje sajmom knjiga

## O projektu

**BookFair** je studentski projekat razvijen u okviru predmeta **Osnovi informacionih sistema i softverskog inženjerstva** na Fakultetu tehničkih nauka Univerziteta u Novom Sadu.

Aplikacija je namenjena upravljanju podacima na sajmu knjiga i omogućava evidenciju posetilaca, autora, knjiga, izdavača i kupovina, kao i upravljanje njihovim međusobnim vezama.

Projekat je implementiran u programskom jeziku **C#**, uz korišćenje **.NET-a**, **WPF-a**, MVC arhitekture i CSV serijalizacije za čuvanje podataka.
